# X6100 CI-V — command set

Status: 2026-10-23. Engine in `src/x6100_civ.c` (`include/x6100_civ.h`), host test
`tests/x6100_civ_test.c`; not yet wired to x6100_trx, serial or LAN. Announces as
IC-705 (`A4`). Specification for the CI-V engine in libx6100 (serial CAT and
the Icom LAN server). Not implemented yet: 02 band edge, 1A 01 band stack, 27 scope.

Sources:

- **Spec:** *XIEGU RADIO CI-V REFERENCE*, version 1.0 (Xiegu PDF, covers X6100,
  G90, G106). Where the tables below say "Xiegu", this is the source.
- **Cross-check only:** x6100_gui `src/cat/civ_processor.cpp` (LGPL-2.1), which
  serves wfview / IC-705 clients over the Icom LAN protocol. Used as a reference,
  no code taken.

## 1. Framing

```
FE FE <to> <from> <cmd> [<sub>] [<data> ...] FD
```

| Item | Value |
|---|---|
| Preamble / end | `FE FE` ... `FD` |
| OK / NG | `FB` / `FA` |
| Controller address | `E0` (typical) |
| Radio address | not stated in the Xiegu reference. Stock X6100 default to verify (0x70 on the G90); x6100_gui uses `A4` (IC-705) so IC-705 clients accept it |
| Levels / meters | 2-byte BCD `0000`-`0255` = 0-100 % |
| Frequency | 5 bytes BCD, little-endian, 1 Hz resolution (Table 2-1) |

## 2. Modes (Table 2-2)

| Data | Mode | libx6100 |
|---|---|---|
| 00 | LSB | `X6100_MODE_LSB` |
| 01 | USB | `X6100_MODE_USB` |
| 02 | AM | `X6100_MODE_AM` |
| 03 | CW | `X6100_MODE_CW` |
| 05 | NFM | `X6100_MODE_NFM` |
| 07 | CWR | `X6100_MODE_CWR` |

Data mode is a separate switch in CI-V (1A 06 or 26); in libx6100 it is the mode
itself: LSB + data = `X6100_MODE_LSB_DIG`, USB + data = `X6100_MODE_USB_DIG`.

## 3. Commands

"x6100_gui" column: **=** implemented the same, **-** not implemented,
**+** extra in x6100_gui (not in the Xiegu reference).

### 3.7 1A: band stack, filter, lock, data mode

| Sub | Data | Function | x6100_gui |
|---|---|---|---|
| 01 | | get band stacking register (Table 2-4) | = |
| 01 | D0, D1 | set band: D0 1-10 = 160 m .. 6 m | = |
| 03 | | get IF filter width (Table 2-5) | = |
| 03 | D0 | set IF filter: **not used** (any value accepted) | = (set commented out) |
| 05 | 00 62 | get lock | = |
| 05 | 00 62 D0 | set lock, D0 00 unlock / other lock | = |
| 06 | | get data mode switch + filter group | = |
| 06 | D0, D1 | set data mode (D0) + filter group (D1) | = |

IF filter width (Table 2-5):

| Mode | Value | Width | Step |
|---|---|---|---|
| SSB / CW | 0-9 | 50-500 Hz | 50 |
| SSB / CW | 10-40 | 600-3600 Hz | 100 |
| RTTY | 10-31 | 600-2700 Hz | 100 |
| AM / NFM | 0-49 | 200-10000 Hz | 200 |

Our filter maximum is 6000 Hz (12 kHz baseband audio): AM / NFM values above 6000
are clipped.

Filter group (1A 06 / 26 D3) maps to our FIL1 / FIL2 / FIL3.

### 3.8 1C: TX and tuner

| Sub | Data | Function | Reply |
|---|---|---|---|
| (none) | | get T/RX status | 1 B: 0 RX, other TX |
| 00 | | get T/RX status | status |
| 00 | 00 / 01 | release / press PTT | ACK (not status) |
| 01 | 00 / 01 / 02 | ATU off / on / start tuning | ACK |

x6100_gui: = (00, 01).

libx6100: PTT from the network is **codec TX** (`x6100_set_codec_tx`, reg 12
`0x4000`) when the audio comes over LAN, PTT `0x40000` when the source is the
microphone. All TX safety rules apply (band check, timeout, SWR, network stall),
see `x6100_netaudio_design.md` §4.

## 4. Not in either

Memories (08 / 09 / 0B), scan (0E), CW send (17), power on/off (18), band edge
table (1E), D-STAR (1F / 20 / 22), voice memory (28).

## 5. Decisions open

1. Radio address: stock X6100 default (to read from the stock UI) vs `A4`
   for IC-705 client compatibility. Probably configurable, default `A4` on LAN.
2. 19 00 transceiver ID: `A4` (IC-705 clients) vs the Xiegu ID via 1D 19 (both can
   coexist: 1D 19 answers `6100`).
3. AGC: how AUTO is reported (16 12 has no AUTO value).
4. S-meter scale for 15 02: Icom 0120 = S9, 0241 = S9+60; the Xiegu doc gives no
   scale points.
5. Commands that change the radio come from one owner: the CI-V engine writes
   through the same radio state as the front panel (x6100d design, §3).
